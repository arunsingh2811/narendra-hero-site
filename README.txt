Narendra Hero site. Plain HTML, no build. Staff admin at /admin (login). Showroom details: config.js. Photos/prices: edit from /admin.
Used bikes: admin > Used Bikes (make, model, year, run, warranty, sale price, 1 to 4 photos). Customers who want to sell their bike use "Sell Your Bike" on the site; you see them in admin > Sell Requests.
Cloudflare Pages: build command empty, output directory "/".
There is no BizBale login link on this site. Staff open BizBale directly from their own bookmark.
Visitor counter: one count per device per day, staff devices and robots not counted. Needs the count_visit SQL. Hide it from the public with showVisitors:false in config.js (counting continues); admin always shows today / 7 days / total.
Admin shortcut: tap the "Website visitors" line (or the copyright line) in the footer 5 times (each tap within 1.5 sec) -> opens this site's /admin login. Switch off with adminLink:"" in config.js.
Bike cards: Admin > New Bikes > Edit has Key points (one per line, best 4), Offer price and Offer valid till. After the date passes the offer hides by itself and the Ex-showroom price shows normally. Needs narendra-bike-cards.sql once.
Social buttons: Admin > Social Links. Paste the Facebook / Instagram / YouTube etc. page links and tick Show; the buttons appear in one line under the phone number, Call and WhatsApp on the home page. Two "Other link" slots are free for any extra site (Justdial, website...). Needs narendra-jobs-and-links.sql once.
Apply for Job: the "Apply for Job" menu button and form on the home page (name, father's name, mobile, alternate number, age, village/city, education, post, experience). Staff see applications in Admin > Job Applications (call, WhatsApp, mark called / closed, note, delete). Needs narendra-jobs-and-links.sql once (run it in Supabase > SQL Editor).
Privacy: job applications contain personal details. In Supabase > Authentication, keep new-user sign-ups switched off so only your staff logins can read them.
Promo reels: Admin > Promo Reels. Add a picture of the reel (a screenshot of the video), a title and the Facebook / Instagram / YouTube reel links. On the home page it shows under the social buttons; tapping the picture opens the reel, and small Facebook / Instagram / YouTube buttons open each link. Up to 6 show. Needs narendra-promo-reels.sql once (run it in Supabase > SQL Editor).
Three different promos: add 3 promo reels in Admin > Promo Reels, one with only the Facebook link, one with only the Instagram link, one with only the YouTube link (each with its own picture and title). A card with one link shows that platform's name on the picture.
